# Avengers Gallery

A visually appealing gallery showcasing Earth's Mightiest Heroes, the Avengers. This project is a static website built with HTML and CSS, featuring images and links to individual pages for each Avenger.

## Features

- **Hero Section**: A bold and eye-catching title with a brief description of the Avengers.
- **Gallery**: A grid of images representing each Avenger, with links to their respective pages.
- **Responsive Design**: Optimized for various screen sizes using CSS.

## Technologies Used

- **HTML5**: For the structure of the webpage.
- **CSS3**: For styling and layout.
- **Google Fonts**: Montserrat font for a modern and clean look.
